## How to start (installation instructions below)

1. Download `WiggleMeTimbers.jsx`.
2. Place it in your After Effects **ScriptUI Panels** folder.
3. Restart After Effects.
4. Open **Window → WiggleMeTimbers.jsx**.

---

## Features

- Quickly apply wiggle expressions.
- Change frequency and amplitude before applying.
- Works with most properties, including:
  - Position
  - Scale
  - Rotation
  - Opacity
  - Effect controls
- Saves time, A LOT.

---

### Requirements

- Adobe After Effects CC 2020 or newer

### Installation

**Windows**

```
C:\Program Files\Adobe\Adobe After Effects <version>\Support Files\Scripts\ScriptUI Panels
```

**macOS**

```
/Applications/Adobe After Effects <version>/Scripts/ScriptUI Panels
```

Restart After Effects after copying the script.

---

## How It Works

The script creates a simple interface for applying the built-in After Effects `wiggle()` expression. Instead of manually writing expressions for every property, you select a property, choose the frequency and amplitude, and apply the expression with one click.
